# 修仙挂机录（vue-idle-xiuxian）

> **一款放置（Idle）修仙题材的网页 / 移动端游戏**：招募宗门角色、研习宗门绝学、突破境界、培养灵宠与丹药，深入八大秘境挂机修炼，挑战变身为角色的「人物形态 BOSS」，打造专属神装，一路问鼎大罗、登临混沌。

- **当前版本**：`2.2.1 · 化器成灵`（2026-08-01）
- **游戏内攻略**：进入游戏后点击「攻略」页（由本仓库 `GUIDE.md` 自动生成，是玩法与数据的**权威手册**）；本 README 为面向玩家的概览与入门。

---

## 一、核心循环（3 分钟看懂怎么玩）

1. **修炼**：在「修炼」页积累**修为**与**灵石**，冲击 126 个境界（练气 → 大罗）。
2. **招募 / 突破**：用抽卡或招募获得 50 名角色（10 宗门 × 5 定位），反复**突破**（最多 5 次，每次全属性 ×1.2）提升战力并解锁皮肤与技能。
3. **挂机**：进入「探索」页选择秘境与难度开始挂机，离线/在线持续产出修为、灵石、幻灵结晶与素材；队伍匹配度达标即可稳定推进。
4. **变强**：用素材强化 / 洗练装备、用八卦炉炼丹加 buff、给角色装备灵宠，并挑战「人物形态 BOSS」收集**内丹碎片**打造**专属装备**。
5. **登顶**：逐级挑战更高秘境与「轮回 / 天劫 / 天道」高级难度，刷取高阶仙品、神品装备。

> 一句话：**修炼攒资源 → 招募突破拉战力 → 挂机刷素材 → 打造装备灵宠 → 挑战人物 BOSS 与高级难度**。

## 三、核心系统速览

### 1. 角色 · 宗门 · 定位
- **50 名角色**（`char_001` ~ `char_050`），每角色有 攻击 / 生命 / 防御 / 速度 四项基础属性与天赋。
- **10 宗门**：剑宗 / 道宗 / 火宗 / 冰宗 / 雷宗 / 毒宗 / 兽宗 / 鬼宗 / 光宗 / 暗宗。
- **5 定位**：先锋（主输出）/ 刀锋（副输出·连击）/ 药引（治疗续航）/ 护法（承伤坦克）/ 掌阵（控场核心）。
- **星级**：3★ / 4★ / 5★（乘率 1 / 1.5 / 2.5），影响基础属性与成长。

### 2. 技能系统（宗门 × 定位）
- 共 **200 个技能**，由 20 个「宗门 × 定位」组合构成，每组合 10 个技能（5 级，每级 1 主动 + 1 被动）。
- 角色**初始**获得 1 级技能（1 主动 + 1 被动）；**每突破 1 次**解锁下一级技能。
- 每角色可装备 **3 个主动技能槽**（`SKILL_SLOT_COUNT = 3`）。

### 3. 突破与皮肤
- **突破**上限 5 次，每次全属性 ×1.2（累计约 ×2.49），并解锁新技能与皮肤。
- **皮肤**：突破 N 次解锁皮肤 N（1:1，皮肤 1~5 由突破解锁）；**皮肤 6 / 7** 仅在灵石阁「皮肤商店」购买（100 万灵石/张）。

### 4. 挂机战斗机制
- **匹配度 = min(战力比, 生存比)**：既看队伍战力，也看队伍有效生命；不足 100% 会持续掉血，**气血归零即力竭提前结束**。
- **防御减伤**：`伤害 ×= 100 / (100 + √(有效防御))`（非线性压缩，堆防御收益递减）。
- **护盾 AI**：护法角色在自身 HP < 50% 时优先自救加盾，否则优先保护无盾队友。
- **锁定**：开始挂机时锁定当前秘境与难度，过程中不可随意切换。

### 5. 人物形态 BOSS（灭世专属）
- 仅「**灭世**」难度的最终 BOSS 会随机变身为某个人物形态（比同图怪物 BOSS 强 ×1.5）。
- 每次挂机结算后按 **60%~80% 概率**（灭世档取上限）为该图指派 1~2 名角色作为候选；一旦指派，灭世难度挑战时 **100% 变身**候选之一。
- 星级随图分配（图 1-3：3~4★ / 图 4-5：3~5★ / 图 6-7：4~5★ / 图 8：5★），确保 50 名角色都能被随机到。
- 击败**必掉 1~2 内丹碎片**，并有 **50% 概率掉 1~2 专属挑战券**；不掉落普通 BOSS 素材。

### 6. 灵宠
- 每位出战角色（玩家自身 + 每个宗门成员）可装备 **1 只**灵宠（无全局栏位上限，收集量受背包限制）。
- 品质：凡品 / 灵品 / 玄品 / 仙品 / 神品（倍率 1.2~2.0），最高 10 星。
- 灵宠按复利放大角色 攻 / 生 / 防 / 速：`倍率 = 1 + 品质基础加成 + (1+星成长)^星 × (1+级成长)^(级-1) − 1`。

### 7. 丹药与八卦炉
- 「八卦炉」页整合**炼丹 / 强化 / 大洗练 / 回炉转生 / 其他锻造**。
- 增益丹药（如聚灵丹、聚气丹、寻宝丹）效果为「**本次挂机**」生效，挂机结束自动清除。
- **高级寻宝丹**：幽冥寻宝丹（+10% 掉落，鬼荒原灭世解锁）、仙墟寻宝丹（+20% 掉落，仙墟灭世解锁）。
- **化器成灵**（2.2.1 新增，位于「回炉转生」子页）：选取 **+12 及以上的仙品/神品装备**与一名宗门人物，将装备 **1/3 基础数值**（攻/血/防/速）**永久融入**人物 `baseStats`，成功后装备消失。仙品 +12 成功率 55%、神品 +12 为 40%，每级 −5%（下限 10%）；**累计失败 3 次必成**；灵石消耗仙品 50 万 / 神品 100 万起，每级 ×1.5。详见游戏内攻略 §10.3。

### 8. 装备与专属装备
- 装备稀有度：凡品 → 下品 → 中品 → 上品 → 极品 → 仙品（权重递增），可强化（上限 +12）与洗练词条。
- **专属装备**：用 1 件**神品**装备 + **100 个该角色内丹碎片** 锻造 6 部位专属神装，对应角色穿戴时整体数值 ×1.3，强化上限 +15。
- **宗门页快捷详情**（2.2.1 新增）：在「修炼」页打开宗门人物详情后，**长按任一装备槽 500ms** 即弹出与背包一致的装备详情页，底部「出售/分解」按钮替换为**「强化」按钮**，可在不切页的情况下直接强化；详情页同时新增**「灵宠详情」按钮**，点击进入该人物所装备灵宠的详情页（与背包灵宠详情一致，支持升级/升星/放生）。

### 9. 商店（灵石阁）
- **皮肤商店**：皮肤 6/7 随机刷新（100 万/张，刷新 10 万/次，每次 5 件，需已拥有 ≥6 款皮肤）；候选池排除 10 位男性角色（因皮肤 6/7 为女性化立绘）。
- **BOSS 挑战券商店**：按权重抽各图挑战券购买（前 4 图 5 万/张、后 4 图 20 万/张，每券每刷最多 20 张，刷新 10 万灵石）。
- 另有**探宝 / 打造货币兑换 / 符文 / 悬赏 / 以物易物 / 黑市**等玩法。

### 10. 抽卡
- 5 个卡池：全能 / 角色 / 装备 / 法宝 / 灵宠。角色池 150 灵石/抽，5★ 保底 50 抽、4★ 保底 5 抽；灵宠池 200 灵石/抽，保底 5 轮必出仙品。

## 四、存档与云存档
- 本地存档采用 **CryptoJS AES 对称加密**（本地密钥）。
- 云存档具备**多档保护**：当本地等级 / 灵石 / 修为 / 装备数量 / 灵宠等级等高于云端一定阈值时，拒绝云端覆盖，并修复了早期 migrate 静默覆盖导致**回档**的问题（非交互模式只上传不下载，本地永远是唯一可信源）。

## 六、技术栈与运行（开发者）

| 类别 | 技术 |
|------|------|
| 前端框架 | Vue 3.5 + Vue Router 4 + Pinia 3 |
| 构建 | Vite 6（Node ≥ 18） |
| 特效 | PixiJS 8（WebGL 序列帧） |
| UI | Naive UI 2.41 |
| 加密 | CryptoJS 4.2（本地 AES） |
| 包管理 | pnpm 9.15.9 |
| 移动端 | Capacitor 8 |

```bash
pnpm install        # 安装依赖
pnpm dev            # 本地开发（默认 http://localhost:2025）
pnpm build          # 生产构建
pnpm preview        # 预览构建产物（端口 2026）
pnpm test           # 运行单元测试（Vitest）
pnpm gen:guide      # 由 GUIDE.md 重新生成游戏内攻略（src/plugins/guideContent.js）
```

> 修改游戏内攻略请编辑 `GUIDE.md` 后执行 `pnpm gen:guide`；`guideContent.js` 为自动生成文件，**请勿手改**。
